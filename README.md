# Guia de A a Z da Desidratação

Página de conteúdo da Meloni Desidratadores: 62 ingredientes e técnicas, de A a Z,
com o que pode ser produzido em um desidratador.

Arquivo único (`index.html`), sem dependências além das fontes do Google.
A logomarca está embutida no próprio arquivo, em base64.

## Publicar

Hospedado no GitHub Pages. Qualquer alteração no `index.html` que chegar
na branch `main` entra no ar em cerca de um minuto.
